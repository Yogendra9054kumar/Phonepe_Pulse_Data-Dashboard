# 📊 PhonePe Pulse Data Visualization Dashboard

## 🔍 Project Overview

This project presents an interactive Power BI dashboard analyzing digital payment trends across India using the PhonePe Pulse dataset.

The dashboard provides insights into transaction growth, user behavior, and state-wise performance.

---

## 🎯 Objectives

* Analyze digital transaction trends (2018–2022)
* Identify top-performing states
* Understand transaction type distribution
* Explore user and brand insights

---

## 🛠️ Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling

---

## 📊 Key Features

* KPI Cards (Total Transactions, Amount, Users)
* State-wise Map Visualization
* Bar Chart for Top States
* Donut Chart for Transaction Types
* Dynamic Filters & Slicers
* Top N Analysis

---

## 💡 Key Insights

* Transactions grew steadily (2018–2022)
* Peer-to-peer payments dominate (~46%)
* Uttar Pradesh and Delhi lead in transactions
* Activity concentrated in key states
* Rapid growth after 2020
